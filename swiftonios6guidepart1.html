The iOS 5 & 6 Setup Guide

One Mac app sets up Xcode 13.4.1 and the Swift toolchains, then builds your app for iOS 5 and 6.

Choose your macOS

The Legacy Swift Development Kit runs on macOS 12 and later. Which Mac are you on?

Your macOS version
1

Downloads

Two downloads: the kit, and Xcode 13.4.1 from Apple. You'll need to sign in with an Apple ID for Xcode. Leave the .xip in Downloads; the kit finds it there.

  • Legacy Swift Development KitGitHub
  • Xcode 13.4.1Apple developer downloads

You don't need to download the toolchains. The kit fetches and verifies them for you.

2

Open the kit

Unzip it and move Legacy Swift Development Kit to Applications. It's ad-hoc signed rather than notarised, so right-click it and choose Open the first time, or run:

On Apple silicon you'll also need Rosetta 2, because the compiler is Intel-only.

3

Install the environment

Go to Environment and set Compatibility mode to Native.

Go to Environment and set Compatibility mode to Modern.

The toolchain manifest is already filled in. Click Install Environment. The kit copies Xcode, downloads both toolchains, checks their hashes, and runs the iOS 5 checks.

Make sure you have about 64 GB free. Your existing Xcode and xcode-select aren't touched.

4

Open a project

Go to Projects / Build. Choose Create Sample Project… to start from a working UIKit app, or Open Project… for one you already have.

Set the minimum iOS version (5.0 to 10) and the architectures (armv7 by default). Each project keeps its settings beside its .xcodeproj.

To edit code, use Open Xcode in the kit and build for Any iOS Device. In Modern mode, don't open the copied Xcode from Finder.

5

Build the IPA

Click Build Unsigned IPA. The kit archives the app, copies in the Swift 5.1.5 runtime, sets the minimum OS version, and packages the IPA. Each build goes in a new folder with its logs; Reveal Output shows it.

Using storyboards or asset catalogs on a recent macOS? Keep a current Xcode in /Applications. The build uses it for those two tools only.

✓

Enjoy your IPA!

It's unsigned, so sign and install it the way you normally sideload to that device. Then test it on the device itself, because a successful build doesn't prove it will launch.

Prefer Terminal? Every build is an editable shell script: Reveal Saved Command shows it. The toolchains are also on GitHub.
